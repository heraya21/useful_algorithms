# Algorithms-and-data-structures

A Python project implementing fundamental data structures and classical algorithms from scratch without external libraries.

## Features

- Binary Search Tree implementation
- Singly Linked List implementation
- Stack implementation
- Queue implementation
- Recursive and iterative tree traversal
- Linked list iterators
- Sorting algorithms
- Tree balancing from ordered lists
- Search operations
- Deep copy operations
- Serialization and reconstruction of trees
- Built-in testing utilities

## Technologies

- Python 3
- Object-Oriented Programming (OOP)
- Data Structures
- Algorithms

## Implemented Data Structures

### Binary Search Tree

Features include:

- Recursive and iterative insertion
- Recursive and iterative search
- Tree traversal
- Tree depth calculation
- Minimum value search
- Deep copy functionality
- Balanced tree construction from sorted arrays

### Linked List

Features include:

- Append and insertion operations
- Node deletion
- Iterators
- Index access
- Selection sort
- Insertion sort
- Quick sort

### Stack

Two stack implementations are included:

- Linked list based stack
- Python list based stack

### Queue

Queue implementation using a linked list.

## Implemented Algorithms

### Sorting Algorithms

Implemented sorting algorithms include:

- Selection sort
- Insertion sort
- Bubble sort
- Shaker sort
- Quick sort

### Tree Traversal Algorithms

- Depth-first traversal
- Breadth-first traversal
- Recursive traversals
- Stack-based traversals

## Goals of the Project

The main objective was to develop a deeper understanding of fundamental data structures, algorithm design, recursion, and traversal techniques through manual implementation in Python.
